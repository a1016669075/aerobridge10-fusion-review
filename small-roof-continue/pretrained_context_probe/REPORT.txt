冻结视觉上下文 DINOv2 ViT-S/14：4景真实输入探针完成

不是重复旧分类器
有限检索当前/前一批PLAN、METHODS、脚本与研究目录，未发现先前DINOv2/冻结视觉编码器。旧23特征为人工定义局地纹理，森林同叶复用了本项目弱标签分类器；本次复用公开自然图像预训练Transformer，没有本项目新训练。官方源代码与权重只存本目录，未安装额外模型库。
环境torch2.14CPU；官方权重88,283,115字节，模型实际22,056,576参数（官方表记ViT-S21M）。4景提取各约0.32秒，384维最后层patch特征；来源/sha见MODEL.json。0新输入拟合、0PM头拟合、0PM推理。

固定尺度与可用信息
原101×101真实10m RGB按既定显示伸展，仅一次放至518；patch14形成37×37token。每token直接覆盖约27.30×27.30m源区域，注意力同时使用全窗上下文。四波段和23特征对照也由相同源像元聚合到该token格，未拿不同分辨率直接比优劣。
新信息来自预训练视觉关系先验，未增加卫星观测。映回原10m网格只显示token归属，没有双线性特征细化，不能识别同token内部哪个10m小格是路/房顶。自然图像训练与卫星域不同；模型输入使用固定RGB伸展，而四带/23直接来自BOA，单一特征距离也受尺度选择影响。
无效源邻域排除直接token比较；全窗注意力仍可能受到灰色缺测或混合地物影响，不能把tokenvalid视为完整上下文纯净。

相同弱种子参照的可分性
当前目标相交token全部从弱种子中剔除，所有对象self_seed_n=0。对每个token/目标，使用160m内空间最近至多7个道路token和7个建筑token，同一套位置用于三种表征；距离为各自L2单位特征余弦距离。没有学习分类头或调层/缩放。
同场逐token留一弱种子平衡一致率（BOA4 / 23 / DINO）：
大庆夏 .7392 / .7736 / .8921
阳泉夏 .6895 / .7505 / .8091
淄博春 .8506 / .7750 / .9335
淄博冬 .7459 / .7114 / .9204
这些是同地图弱标签、邻近参考的探索性可分性，不能叫独立材料准确率，更不是PM精度。特征池没有使用PM值/结果。

当前小亮对象与固定风险
共73当前对象，71同时有有效token与双类局地参照；其中48个只有一个token支持。29对象的道路/建筑距离差符号与23特征不同，说明并非简单重现手工输入，但无目标材料真值时不能把翻转全部判正确。
固定位置具体分数见FIXED_FOCUS.csv与局部图，尤其大庆夏[17,2]处DINO偏建筑而23偏道路；该对象仅一token，附近屋面/道路混合和全窗上下文都可影响结果。必须保留这个风险，不能仅依靠种子总体一致率决定下一轮自动扣量。
固定淄博[54,9]的DINO距离差春−.110416、冬+.174354，方向翻转，23为−.035389/−.025077；春并非本日COMPACT目标，冬是。该图更像道路与屋面结构并不保证同址材料稳定，不能把较高弱种子一致率当成已解决跨季问题。阳泉夏固定位置DINO+.002381，接近两类等距，而非可靠建筑判断。
相同淄博春/冬场保留其分数与RGB差异；没有为了更高指标替换场景。不是完整四季稳定性试验。

判断
CPU/依赖/公开权重可行；冻结视觉表征在相同token支持与弱参考下四场均提供更好的局地类分离线索，值得作为新的上下文信息继续有界研究。其27m直接粒度仍不能直接解决10m单个小屋顶；不能用DINO token标签覆盖原10m细节。下一步若继续，应明确只提供上下文材料信息，并保留原生像元变化与混合token风险；本探针未授权或生成206 PM候选。
