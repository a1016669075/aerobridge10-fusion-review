B-Gaussian × ERASE 融合首轮试验

目的：在已有两种输入修正方案之间按位置调整权重，查看屋顶、高亮、道路和工业区域的取舍。
范围：原6个代表场景，加上已选30场，共36场；所有场景都有实际保存的两种专家输入与反演结果。

三种融合（规则在查看本轮结果前固定）
MEAN50：ERASE权重恒为0.5。
MAT_GATE：将原四波段与同位置原生20m SWIR组成六带上下文，比较它与两种白色材料和26种其他材料的光谱方向。
          dW是离白色材料最近的光谱角，dN是离其他材料最近的光谱角；ERASE权重=dN/(dW+dN)。
MAT_CONTEXT：先依据原光谱相似度在3×3邻域平滑MAT_GATE权重，再乘建筑分类领先分数与10m子格/20m父格光谱一致性。
             目的是减少材料混合边缘的错误切换；该乘法也可能使结果更接近B-Gaussian，需要结合图和局部统计检查。
两种自适应权重均为本轮预设工程规则，未训练新的门控模型，也不是经校准的专家正确概率。
材料谱来自项目现存S2A/S2B传感器积分先验；SWIR的原生分辨率仍为20m。

实际计算
X_fused=(1-w)*X_B + w*X_ERASE；只融合可见光，NIR逐值保留原输入。
随后调用同一原PM线性回归头，加上原B58背景。
由于PM头线性，结果与(1-w)*PM_B+w*PM_ERASE数值等价，本轮逐场验证。
固定凸组合的每个像元都位于两种专家结果之间。两种专家都缺少的细节，单靠这次融合不能补回。
没有将两种扣量相加，没有按“谁的PM低就选谁”分派，也没有改变原有效像元支持。
原专家、原科学栅格和训练扩样任务不变；本发布目录仅包含静态展示资源。
